# Geographical context

`map-outlines.json` contains country geometry and names extracted from Natural Earth's 1:110m admin-0 countries dataset. Downloaded 22 November 2026 from the [Natural Earth repository](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson). All other source properties were removed to reduce the client payload.

Natural Earth data is [public domain](https://www.naturalearthdata.com/about/terms-of-use/). The bundled geometry supplies low-resolution geographical context beneath online OpenStreetMap tiles. It is not an authoritative administrative or impact-boundary map.

OpenStreetMap tiles retain their own visible contributor attribution and remain subject to [OpenStreetMap's tile usage policy](https://operations.osmfoundation.org/policies/tiles/).
